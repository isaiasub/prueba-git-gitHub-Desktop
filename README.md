# prueba-git-gitHub-Desktop
Prueba entender comandos git y GitHub Desktop.

## Primer programa en Java

El programa `HolaMundo.java` imprime un saludo en la consola.

Para compilarlo y ejecutarlo, abre una terminal en esta carpeta y ejecuta:

```bash
javac HolaMundo.java
java HolaMundo
```

La salida será:

```text
¡Hola, Mundo!
```
